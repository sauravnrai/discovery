Know what your score means.

Five weights, no hidden model

Every scored answer is an integer 0–4. Clarity and quality carry 25 points each, approved-data access 20, ownership and pilot capacity 15 each. Multiply weight × answer ÷ 4, add contributions, then round once.

Below 40: prepare foundations. From 40 to 69: small pilot. From 70 to 100: focused pilot. These self-reported bands are not probabilities, certification, AI inference, or promises.

Four new context questions

  • Format: CSV, flat JSON, or no file changes import advice.
  • Audience: personal, team, or stakeholders changes the reporting checklist.
  • Timing: today, this week, or later changes the pilot plan.
  • Data-use status: synthetic, approved non-sensitive, or unapproved changes safety guidance.

Context changes advice, not points. Low access or unapproved/sensitive data triggers a synthetic-only gate even when other answers produce a high score. Shared-origin storage is not a secure vault.

Explainable recommendations

Your goal orders Studio, Analytics, and Visualizer. The two lowest readiness answers set initial actions; weighted ties are stable. The largest weighted gap shows the biggest point opportunity. At 100, validate assumptions with a pilot rather than inventing a gap.

Complete results, no gate

See every answer and contribution, point gaps, data-use warning, all tool links, next steps, and context plan immediately. Copy or download TXT/JSON. Editing answers invalidates old reports and draft links until regeneration.

Offline, honestly described

A successful first HTTPS visit in a supporting browser caches the questionnaire, this guide, and the examples. Answers and reports are not cached. Browsers may evict cached files. The self-contained offline HTML download excludes current answers, report, and score; open the downloaded file directly without a connection.

Other apps, GitHub sources, and email providers are not included. If caching is unsupported, download the HTML. Discovery’s versioned cache does not delete ASF storage.

Optional email is draft-only

Both draft buttons address commercial@ziontechgroup.com and prefill the complete report. Gmail opens a Google draft; the Mail App button uses mailto. Review the recipient and report, then click Send yourself. Nothing sends automatically; delivery is not tracked or verified. Long URLs can truncate, so use copy/download when needed.

No external form services, uploads, runtime API keys, tracking, external fonts, or third-party libraries. Ordinary hosting requests still go to GitHub Pages.
